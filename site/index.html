How the Marlowe points were measured

  1. Simulated speculative acceptance. Every Marlowe point runs with a simulated accept length of 3.51 (SGLANG_SIMULATE_ACC_LEN=3.51, match-expected, real-draft-token), as InferenceX's CI sets for DeepSeek-V4.1-Flash's DSpark speculative decoding. The measured mean accept length was 3.51 on every run.
  2. Measured by Marlowe, not by InferenceX CI. We ran InferenceX's own client (agentx-harness 1.0.13, agentx preset, 3600 s, sequential trace replay) and scored the results with InferenceX's formulas (agentx-audit-data windows.py, full window), on our own MI355X nodes with a build that is not a published image. InferenceX has not reviewed or reproduced these numbers.
  3. Shared nodes. Several servers shared each 8-GPU node on disjoint GPUs (four TP2 or two TP4 servers), each pinned to its own socket's CPU cores, with the client on the same node. InferenceX runs one server per node.
  4. Request caps. Some points cap concurrent decoding requests (--max-running-requests, e.g. 1 at C1 and C2, 2 or 4 on the interactivity-leaning points). Requests over the cap wait in the queue, so the wait shows in TTFT, not in interactivity. Each point's cap is on hover and in its recipe.
  5. Engram host table on at TP2. At TP2 the model only fits with the Engram tables in host memory (the InferenceX MI355X SGLang recipe's setting); at TP4 and TP8 they stay on the GPU.
  6. Builds. TP2 and TP4 points: image lb-sgl1a16c3def9-mono3c777011, MarloweAI/sglang 1a16c3de (marlowe-dev 08d1e520) + sgl-amd-mono 3c777011 + marlowe-mix edde9499. TP8 C1: image lb-sgl2ad94ff74d-mono5c4c0d20, MarloweAI/sglang 2ad94ff7 (marlowe-dev ab55bd11) + sgl-amd-mono 5c4c0d20 + marlowe-mix edde9499; it changes only bookkeeping and TP8 start-up, not the TP2/TP4 kernels. Both run InferenceX's MI355X SGLang agentic recipe with Marlowe's MoE runner and monokernel added; no point uses DP attention.
  7. Throughput counts input tokens, cached ones included, plus output tokens, per GPU (InferenceX's convention). Interactivity is 1/TPOT per request.

SemiAnalysis and InferenceX have not reviewed or endorsed the Marlowe results on this page.
